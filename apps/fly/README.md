# Муха и её настоящий мозг

Страница: `web/fly/index.html` → открывается по адресу `https://krupalex14-cell.github.io/tokyo-drift1/fly/`
(публикуется тем же GitHub Pages, что и шахматы; один файл, всё внутри, интернет не нужен).

Что можно делать: кормить и поить (сахар, вода, горькое, смеси), пугать (ветер, хлопушка), трогать и гладить, учить запахам (награда и наказание).
Внизу — мозг: 700 нейронов настоящего коннектома, яркость = частота спайков, плюс частоты входов и выходных нейронов.

## Что здесь настоящее, а что моё

**Настоящее**
- Связи: коннектом взрослой самки дрозофилы FlyWire, версия 630 (127 400 нейронов, 14,7 млн синапсов), файлы из <https://github.com/philshiu/Drosophila_brain_model>.
- Модель нейрона и постоянные — из Shiu et al., *Nature* 2024 («накопил заряд — выстрелил», Пуассоновская стимуляция входных нейронов).
- Таблицы откликов (`data/responses.json`) посчитаны `sim/make_responses.py` на всём мозге: сахар, горькое, вода, «ветер на усики» при 0/50/100/150/200 Гц, плюс сетки для смесей сахар+горькое, сахар+вода, горькое+вода. Среднее за 100–400 мс, 3 запуска.

**Моё (не из коннектома)**
- `sim/fast_lif.py` — моя событийная numpy-реализация той же модели (быстрее оригинала на Brian 2). **Сверку с оригиналом на Brian 2 не делал**: проверено только, что число активных нейронов (~400 при сахаре 150 Гц) и отклик MN9 по порядку величин совпадают со статьёй.
- Тело, походка, «подойти к капле», «отшатнуться от горького», «вздрогнуть» и «взлететь» — простые правила, которые смотрят на частоты выходных нейронов: MN9 → хоботок, aBN1 → груминг, DN1/DN2 → испуг. Первые два — по статье, «испуг» — моя трактовка.
- Ветер, хлопушка, тычок и поглаживание — один и тот же вход на механосенсорные нейроны усиков (JO). В модели нет ни зрения, ни осязания ног.
- Яркость нейронов для смесей — сумма откликов по отдельности; выходные нейроны на смесях взяты из отдельных расчётов на парах. Если смесь из трёх веществ — берутся два сильнейших.
- Обучение запахам — упрощённая модель грибовидных тел (разреженный код + дофаминовая правка весов). Это не коннектом: в нём веса фиксированы и учиться он не умеет. Награда/наказание подают на мозг настоящий сахар/хинин, но запоминание — игрушечное.
- Отклики на странице — готовая таблица с интерполяцией и сглаживанием, не симуляция «вживую».

## Как пересобрать

```bash
# 1. два файла из репозитория philshiu/Drosophila_brain_model положить в DATA_DIR:
#    2023_03_23_completeness_630_final.csv и 2023_03_23_connectivity_630_final.parquet
pip install numpy pandas pyarrow scipy
python3 sim/make_responses.py DATA_DIR out single                    # ~1 мин
python3 sim/make_responses.py DATA_DIR out pairs sugar_bitter        # ~1 мин, и так же sugar_water, bitter_water
python3 sim/make_responses.py DATA_DIR out final                     # → out/responses.json
cp out/responses.json data/responses.json

# 2. собрать страницу (нужен three.js r128)
npm i three@0.128.0
python3 page/build_page.py data/responses.json node_modules/three/build/three.min.js ../../web/fly/index.html
```

Файлы страницы: `page/style.css`, `page/body.html`, `page/main.js`; `build_page.py` вшивает в них three.js и данные.
Для тестов в браузере есть `window.__fly` (`advance(сек)`, `snap()`, `api.*`).
