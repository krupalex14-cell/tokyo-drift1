# Космос — 2D-пиксельный симулятор ракет «со смыслом»

Страница: `web/space/index.html` → `https://krupalex14-cell.github.io/tokyo-drift1/space/`
(один файл ~525 КБ, шрифты внутри, интернет не нужен; сохранение — в localStorage браузера).

Идея: собрать настоящую ракету из настоящих деталей, запустить зонд, измерить что-то на другом теле, передать данные, выполнить контракт, открыть следующий уровень техники.

## Как играть
- **🚀 Готовые ракеты** (центр управления): Electron, Falcon 9, Atlas V, Saturn V, Starship, суборбитальная ракета и вездеход (Луна/Марс) — уже собраны, пуск бесплатный, «автопилот» сам выводит на орбиту 200 км. «В ангар» открывает ракету, чтобы разобрать. Каждая проверена виртуальным полётом (орбита ~200 км).
- **Ангар** (в стиле Spaceflight Simulator): тап по детали — встаёт к выбранной (стрелки «↑↓←→», симметрия); **потяните деталь вверх на поле** — магнит ищет стыки (зелёная рамка и полоска на стыке), между ступенями деталь раздвигает стопку; выбранную деталь можно двигать пальцем, она тоже липнет. Размеры, кластеры двигателей, ступени — в карточке детали. Шаблоны разбиты на «Ракеты / Зонды / Вездеходы».
- **ⓘ Справка по деталям**: значок «i» на плитке (или удержание, или кнопка «что это» у выбранной детали) — «зачем нужна», «как использовать», настоящие характеристики и прототип (src/info.js).
- **✨ Автосборка**: собрали зонд — выбираете цель (орбита Земли или любое тело системы), ИИ подбирает двигатели, баки, ступени, обтекатель и **проверяет каждую ракету виртуальным полётом** автопилота. Предлагает 3 варианта («Эконом / Надёжная / Мощная»). Запуск миссии сам выходит на орбиту, ждёт окно, даёт разгонный импульс, отделяет зонд, делает коррекцию и торможение у цели.
- **Полёт**: тяга, штурвал, SAS, РСУ, ступени, масштаб времени, автопилот (выход на орбиту, скругление), приборы, раскрытие панелей/опор/парашютов.
- **Карта**: орбиты, манёвры (изменить орбиту, скруглить), маршрут к другому телу (задача Ламберта → окно и точный импульс).
- **Контракты / Наука / Технологии**: очки науки за первые измерения (кодекс — настоящие факты), деньги за контракты, 5 уровней техники.
- **Читы**: нет гравитации, бесконечное топливо/энергия, не разбиваться, не нагреваться, парашюты без предела, **наложение деталей**, **бесконечное поле**, все детали бесплатно, мгновенная наука, +деньги/наука, все технологии, телепорт на орбиту/поверхность, заправка и ремонт.
- Вселенные: Солнечная система, TRAPPIST-1, случайная (seed). Режимы: карьера / песочница.

## Что настоящее, а что моё
**Настоящее**
- Физика: СИ-единицы, законы Кеплера, сфера влияния, сопла и Isp из паспортов двигателей, уравнение Циолковского, атмосферы по таблицам плотности (давление, скоростной напор, нагрев), вращение тел.
- Тела Солнечной системы: радиусы, массы, орбитальные элементы (J2000), периоды вращения, атмосферы. TRAPPIST-1: орбиты и размеры.
- Детали — реальные (Rutherford, Merlin 1D, RL10, J-2, РД-180, F-1, RS-25, Raptor, NERVA, NSTAR, GEM 63, Space Shuttle SRB, MR-80B «небесный кран», Draco, LM/AJ10, колёса ровера MSL/Curiosity, камера Mastcam, лазерный альтиметр LOLA и т.д.). Тяга, Isp, масса, габариты — по открытым данным (округлены).

**Моё / упрощено**
- Метод «сопряжённых конических сечений» (patched conics), без N тел: нет точек Лагранжа, нет возмущений от Луны/Солнца на орбите вокруг Земли.
- Рельеф и биомы **процедурные**: у Земли и Луны это не карты настоящих гор/морей. У TRAPPIST-1 и случайных систем поверхности и атмосферы гипотетические.
- Цены, уровни техники, награды за контракты, баланс науки — мои числа для игры. Кодекс — реальные факты, но краткие.
- Тепловая модель, аэродинамика, прочность, связь (прямая видимость тел, скорость передачи зависит от антенн и расстояния), энергия (солнечные панели, батареи, ночь) — упрощённые игровые модели, не инженерный расчёт.
- Автосборка ориентируется на аналитический Δv и проверяется моим автопилотом — это не гарантия «реальной» оптимальности; кластеры из многих двигателей — следствие ограниченного набора деталей на низких уровнях.
- Не проверялось на настоящем телефоне: тестировал в Node (физика, автосборка) и в headless Chrome (интерфейс, полёт на орбиту, сохранение).

## Сборка
```bash
python3 build.py ../../web/space/index.html      # собрать одну страницу
MODS=util,bodies,parts,orbits,planner,vessel,physics,world,science,autobuild,templates node tests/t22.js   # пример физического теста
python3 drive.py steps.json file:///.../index.html   # скриншоты headless Chrome (нужен playwright)
```
Модули в `src/` собираются по порядку из `build.py` (ORDER). Шрифты: TokyoPx (тот же пиксельный шрифт, что в основной игре, + пиксельные Δ Σ π ≈ ← → ▶ ▼) и Unifont (как в шахматах) для запасных символов — в `fonts/`.
